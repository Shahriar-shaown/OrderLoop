# Dependencies and status

One row per feature or integration, stating honestly what works, how far it was tested, what activates it and who owns that. Compiled
on 2026-10-21 from the repository docs (`docs/couriers.md`, `meta.md`, `automation.md`, `finance.md`, `mobile.md`, `known-issues.md`,
`api.md`) and code. "Tested locally" means automated tests and/or manual runs against local PostgreSQL, Redis and Mailpit, with
fictional data. **It does not mean tested against any real third-party service, at production scale, or on a real phone**, unless the row says so.

**Status vocabulary:** Working and tested locally / Mock only / Disabled by default / Awaiting credentials / Awaiting platform approval / Not built.

**Owner** columns hold roles to be assigned (`<name>`); the project does not know your people.
